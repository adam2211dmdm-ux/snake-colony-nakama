Snake Colony — تشغيل سيرفر Nakama مجاناً على Railway (بدون كارت)
============================================================

الملفات هنا:
- Dockerfile : صورة Nakama 3.26.0 مع سكربت التشغيل
- start.sh   : ينفذ ترحيلات قاعدة البيانات ثم يشغل السيرفر
- README_AR.txt : هذا الملف

الخطوات (من التليفون):
1) اعمل حساب GitHub مجاني (github.com/signup) — بدون كارت.
2) اعمل مستودع جديد (مثال: snake-colony-nakama) وارفع إليه هذين الملفين
   (Dockerfile + start.sh) من صفحة المستودع: Add file ← Upload files.
3) اعمل حساب Railway مجاني (railway.app) — سجل بالـ GitHub، بدون كارت.
4) في Railway: New Project ← Deploy from GitHub repo ← اختر المستودع.
5) داخل المشروع: + New ← Database ← PostgreSQL.
6) افتح خدمة Nakama ← Variables ← أضف:
   DATABASE_URL = ${{Postgres.DATABASE_URL}}
7) افتح خدمة Nakama ← Settings ← Networking ← Generate Domain،
   واختر المنفذ المستهدف 7350 عندما يُسأل عنه.
   سيظهر دومين مثل: xxx.up.railway.app
8) في اللعبة (نسخة 3.6.1): الإعدادات ← 🌐 سيرفر الأونلاين ← اكتب:
   https://xxx.up.railway.app
   (أو xxx.up.railway.app:443) ← حفظ العنوان ← ابحث عن مباراة.

ملحوظات:
- الرصيد المجاني 5 دولار لمدة 30 يوماً، يكفي حوالي أسبوع إلى أسبوعين
  تشغيلاً متواصلاً. أوقف الخدمة من لوحة Railway عندما لا تلعب لتطيل المدة.
- الخدمة قد "تنام" عند عدم الاستخدام في الخطة المجانية؛ أول بحث عن
  مباراة بعد فترة توقف قد يفشل مرة ثم يعمل عند إعادة المحاولة.
- لا تضع كلمة سر الكونسول هنا — الكونسول (7351) غير معرّض للإنترنت
  في هذا الإعداد، فلا حاجة له.
- بعد انتهاء التجربة: إما VPS مدفوع (~6-7 دولار/شهر) أو Oracle Cloud
  المجاني إن توفر لديك كارت للتحقق.
