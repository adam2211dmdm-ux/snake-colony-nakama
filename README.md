# سيرفر Snake Colony على Railway — ديمو مجاني من غير كارت (من التليفون بس)

الملفات دي بتشغّل سيرفر Nakama بتاع اللعبة على **Railway** بالتجربة المجانية:
**5 دولار رصيد لمرة واحدة، 30 يوم، من غير كارت خالص** (حسب docs.railway.com/pricing/free-plan).
بعد الـ 30 يوم (أو لما الرصيد يخلص) الحساب بيقلب على الخطة المجانية (1 دولار/شهر)
والسيرفرات فيها بتنام — يعني دي **فترة ديمو**، مش استضافة دائمة.
الاستضافة الدائمة الرخيصة لسه هي VPS (Hetzner ~€6/شهر) أو Oracle المجاني (محتاج كارت).

## قبل ما تبدأ: لازم نسخة اللعبة v3.6.1 أو أحدث
النسخة v3.6 كانت بتتصل بالسيرفر على منفذ 7350 بس، وRailway بيدّي منفذ عشوائي
(مثال: `xxx.proxy.rlwy.net:15140`) — فاللعبة اتعدّلت في v3.6.1 عشان خانة
السيرفر في الإعدادات تقبل `host:port`. حدّث اللعبة الأول، وبعدين كمّل.

## الخطوات (من Chrome على تليفونك)

### 1 — اعمل حساب GitHub (مجاني، من غير كارت)
- افتح github.com/signup واعمل حساب (إيميل + باسورد + اسم مستخدم)، وأكّد الإيميل.
- ده كمان بيأكّد حساب Railway (من غيره Railway ممكن يقيّد حسابك).

### 2 — اعمل مستودع (Repo) وحطّ فيه الملفات دي
- على github.com: زر **+** فوق → **New repository** → الاسم `snake-nakama` → **Public** → Create.
- في صفحة المستودع: **Add file → Upload files** → ارفع الملفات التلاتة:
  `Dockerfile` + `entrypoint.sh` + `railway.json` → **Commit changes**.

### 3 — اعمل حساب Railway واربط المستودع
- افتح railway.com → **Login** → **Login with GitHub** (نفس حساب الخطوة 1).
- **New Project → Deploy from GitHub repo** → اختار `snake-nakama` → **Deploy Now**.
- أول Build بياخد حوالي 3–5 دقايق (بينزّل Nakama + CockroachDB).
- من صفحة الـ Deployments → **View Logs**: لازم تشوف في الآخر `Startup done`
  (النص اللي قبله `Applying database migrations` ممكن ياخد دقيقة — ده طبيعي).

### 4 — احفظ البيانات (Volume) — مهم عشان الحسابات متضيعش
- في المشروع: **+ New → Volume** → اختار السيرفر → **Mount Path: `/data`** → الحجم 1GB.
- اعمل **Redeploy** للسيرفر بعدها. من غير Volume السيرفر شغّال عادي،
  بس أي Redeploy هيمسح حسابات اللاعبين (واللعبة هتعمل حسابات جديدة أوتوماتيك).

### 5 — افتح المنفذ للعبة (TCP Proxy)
- افتح السيرفر → **Settings → Networking → TCP Proxy** → اكتب المنفذ `7350`.
- هيطلع لك عنوان زي: `shuttle.proxy.rlwy.net:15140` — **انسخه كله بالمنفذ**.

### 6 — وصّل اللعبة
- افتح Snake Colony v3.6.1 → **الإعدادات → 🌐 سيرفر الأونلاين** →
  الصق العنوان كامل (`xxx.proxy.rlwy.net:15140`) → **حفظ العنوان**.
- دوس **بحث عن مباراة** — لو حد تاني فاتح اللعبة بنفس العنوان هتلاقيه (🌐).
- صحابك في الديمو: نفس الـ APK ونفس العنوان في الإعدادات عندهم.

## الفلوس — بصراحة
- السيرفر ده بيستهلك حوالي **0.5 جيجا رام + شوية CPU** طول ما هو شغال،
  وRailway بيحاسب بالثانية: الرام ~10 دولار/جيجا/شهر والـ CPU ~20 دولار/وحدة/شهر.
- يعني الـ 5 دولار بتوع التجربة يكفّوا تقريباً **أسبوعين لـ 3 أسابيع ديمو شغّال على طول**.
- عشان تمدّها: من لوحة Railway اعمل **Stop** للسيرفر لما متلعبش، و**Deploy** لما ترجع
  تلعب (السيرفر بيصحى في أقل من دقيقة). وانت واقفه مبيتحاسبش.
- لما الرصيد يخلص: الخدمة بتقف لحد الشهر الجديد (1 دولار). ساعتها يا تشتري
  خطة Hobby (5 دولار/شهر) يا تنقل على VPS — السكربت بتاع الـ VPS جاهز أصلاً.

## ملحوظات أمان للديمو
- المنفذ 7351 (لوحة تحكم Nakama) **مش** مفتوح للإنترنت — محدش يقدر يدخل عليها.
- مفتاح السيرفر هو الافتراضي `defaultkey` — أي حد معاه العنوان يقدر يعمل حساب
  ويلعب. للديمو تمام، بس متشاركش العنوان غير مع اللي هيلعبوا معاك.
- غيّر باسورد لوحة التحكم لو فتحت 7351 في أي وقت (الافتراضي `admin` / `password`).
